# 今後の課題

現在の到達点：複数ストローク・A/B・色補間・オプションを備えた編集と、長辺5000pxまでのsRGB 8bit PNG出力。ここから先の評価・実装項目を挙げる。

## 評価待ち

実装済みでも、美的な評価と印刷品質の確認は完了扱いにしない。

- 実際の写真でのA/Bの見た目、採取線の操作感、Bの各色補間方式の使い分け。
- 太い帯の折り返し・自己交差・端点の見え方が意図に合うか。合わなければ編集UIを増やす前に加工方式を見直す。
- 100%表示での色の筋・輪郭・ぼけ・階調の段差の確認。
- 5000px時の編集の体感速度と、読み込み・再計算・書き出しの処理時間。

## 未実装（次の段階）

- **作品データの保存・再読込**：元画像と編集情報をまとめて保存する。現在は再読み込みで全て失われる。
- **印刷向けの色管理**：ICCプロファイルの保持、広色域・16bit出力、最終ファイル形式の確定。現在はsRGB・8bit PNGのみ。
- **紙対応**：余白・切り抜き、印刷サイズのメタデータ。現在は写真の縦横比と長辺pxのみ。
- TIFF・RAW入力は引き続き対象外。

## 判断が必要な事項

- 操作中だけ低解像度で描画するプレビューの採否。採用する場合も確定表示とエクスポートはフル解像度を維持する。
- ドラッグ中の再計算方針（毎フレーム再計算か、確定時のみか）。実機の処理時間を見て決める。

## 検討中の表現アイデア

- ストロークごとのブレンドモード（乗算・スクリーン・加算など）。重なりを上書きではなく発色にする。
- 周波数分離：写真を色（低周波）と質感（高周波）に分け、色だけを流して質感を元の位置に残す。
