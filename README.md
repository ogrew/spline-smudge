# Spline Smudge

写真の色をスプラインに沿って引き伸ばす、TypeScript + WebGL2 + GLSLのブラウザツール。写真1枚に複数のスプラインを重ね、作品全体でA/Bを切り替えられます。

## 起動する

Node.js 22.18以上（検証環境：24.4.1）を使用します。

```sh
cd /Users/ayato/spline-smudge
npm install
npm run dev
```

[http://127.0.0.1:5173/](http://127.0.0.1:5173/) を開きます。停止はターミナルで `Control + C`。PC再起動後は同じフォルダで `npm run dev` を実行すれば再開できます。普段の起動では `npm install` は不要です。

既存のp5版（ポート8765）とは独立しています。5173が使用中の場合は、以前のSpline Smudgeサーバーが動いていないか確認してください。

## 最初に試す

1. 最初は比較用の生成パターンと、ランダムな4〜12点の曲線が表示されます。「画像を選択」で手元のJPG／PNGを選びます。
2. 写真上をクリックして点を追加。ドラッグで移動、点をダブルクリックすると削除します。空白部分のダブルクリックは点を追加しません。
3. 点を選択し「この点の太さ」を0〜10倍で調整します。前後へ滑らかにつながります。
4. Aでは始点の採取線を編集します。Bでは各点に採取線があり、点をクリックして、その点の角度・長さを調整します。選択中の採取線を明るく表示します。採取位置は点に追従します。
5. **A：色の帯**は始点で採取した色の並びを保ちます。**B：点ごとの色**は各点で元写真から採取し、隣り合う2本の採取線の色の並びを滑らかにつなぎます。混ぜ方は「Bの色補間」で選びます（後述）。通り道の色を逐次拾う旧Bとは異なります。
6. 長辺2000／3508／5000px、または元画像と同じサイズを選びます。縦横比は変わりません。
7. 「エクスポート」で、点・番号・ガイドのない画像を保存します。

「ランダムな曲線」で点を置き直せます。A/Bで点位置と太さは共通です。Aの採取設定とBの各点の採取設定は独立して保持し、切り替えで失われません。新しい点の採取角度・長さの初期値は、その時点のA設定からコピーします。

## 表示と編集

### 複数の線

- スプライン欄の一覧から編集する線を選びます。選択した線だけに点・番号・採取線のガイドを表示します。
- スプライン種類は作品全体で共通です。線一覧の上の選択を変えると、非表示の線も含む全線へ適用されます。追加・複製した線も同じ種類を使います。
- 「＋ 追加」で空の線を最前面に追加します。初期の太さ・採取設定は選択中の線を引き継ぎ、その後は独立して編集できます。
- 「複製」は同じ位置・形・設定のコピーを最前面に追加します。コピーの点や設定を変えても元の線には影響しません。
- 一覧の上が手前です。「↑」で手前、「↓」で奥へ移動します。順序を変えてもStroke番号は変わりません。
- 各行のチェックで表示／非表示を切り替えます。非表示の線はガイドとエクスポートからも除外し、キャンバス上の点操作を受け付けません。設定は保持します。
- 「削除」で選択した線を削除します。最後の線を削除すると、新しい空の線が1本残ります。「点をクリア」は選択した線の点だけを消します。
- 「ランダムな曲線」は選択した線だけを置き換えます。B用の採取線も点ごとに独立してランダム化し、角度は−180〜180°、長さは元画像の短辺の5〜50%から選びます。Aの採取角度・長さは保持します。
- ランダム生成時の各点の太さは、前後の制御点との角度で決まります。90°未満は2〜10倍、90〜180°は0〜0.5倍から0.05刻みでランダムに選びます。両端と隣接点が重なって角度を定義できない点は1倍です。生成後は手動調整でき、点を動かしても倍率を自動計算し直しません。
- 追加・複製・削除・表示切り替え・前後移動も取り消し／やり直しに対応します。
- A/Bとスプライン種類は作品全体で共通。点・太さ・TCBの調整値・Aの採取線・Bの各点の採取線は、線ごとに保持します。採取元は他の線の描画結果ではなく元画像です。

### 表示・履歴

- 基本幅や採取長さのpxは**元写真の座標**です。出力を大きくすると作品全体が比例して拡大します。元画像の長辺2000pxで幅20pxなら、長辺5000px出力では50pxです。
- 「基本の太さ」は整数pxです。上限は元画像の長辺÷10の小数部分を切り捨てた値（最低1px）。長辺2000pxなら200px、6000pxなら600pxで、1px刻みで調整できます。各点の0〜10倍はこの基本幅に掛かります。
- 点を選んで「1.00× に戻す」を押すと、その点の太さだけを1倍に戻せます。取り消しにも対応します。
- 点を選択中、画像上でShift＋上スクロールで採取角度を増やし、Shift＋下スクロールで減らします。Aでは始点の採取線、Bでは選択点の採取線を調整します。±180°を越えると循環します。通常スクロールはズームです。Shift中は点が未選択でもズームしません。連続する角度スクロールは1回の取り消しにまとめます。
- 「全体」で画面に収め、「100%」で出力の1pxを画面上の1 CSS pxに対応させます。ホイールはカーソル位置を中心に拡大縮小し、＋／−は画面中央を中心に動きます。Space＋ドラッグまたは中ボタンで表示を移動できます。
- 「ガイド」1つで番号・点・補助線・採取線をまとめて表示／非表示にできます。非表示でも編集できます。
- `⌘/Ctrl + Z` で取り消し、`⌘/Ctrl + Shift + Z` でやり直し。履歴は最大80件、同じ写真の編集中だけ保持します。
- 計算中も編集できます。古い計算を中断し、最新の編集で再計算します。「中断」またはEscapeで止めた場合は「再計算」を押してください。未完成画像は書き出せません。

曲線はCatmull–Rom、B-spline、Centripetal Catmull–Rom、Natural cubic、Kochanek–Bartels / TCBの5種類。TCBでは張り・つながり・偏りを調整できます。B-splineは通常内部の制御点を通らず、点の太さは対応する曲線上の位置（Greville位置）に作用します。

## オプション

サイドバー「04 オプション」の2機能で、帯の見え方を写真に反応させられます。どちらも既定OFFで、**OFFのときの出力は従来と完全に一致**します。チェックを入れると設定が現れます。設定は作品全体に効き、取り消し・エクスポートに対応します。

- **写真で帯を変形**：2つのアルゴリズムから1つを選びます。アルゴリズムごとの調整値は、切り替えても保持されます。
  - *輝度ディスプレイスメント*：帯の各位置を、その場所の写真の明るさに応じて帯の法線方向へ押し出します。変位量は元画像の短辺に対する％で、負の値で方向が反転します。
  - *エッジで幅を変調*：写真の輪郭の強さに応じて帯の幅を伸縮します。効きが正でエッジ部分が太く、負でエッジ部分が細くなります。
- **フェイク3D**：帯の断面に円筒状の陰影とハイライトを付け、リボンの物質感を出します。強さは0〜1（初期値0.65）、光源は左上固定です。

採取線・A/B・エクスポートの仕様は変わりません。

## 画像・出力の仕様

- JPG／JPEG、PNG入力。JPEGの向き情報を反映し、元ファイルとデコード画像をタブ内に保持します。
- **sRGB・8bit PNG出力**。透明部分は背景色に合成します。元のICCプロファイル／16bit精度をそのまま保つ制作版の色管理は未実装です。
- 出力名：`作品全体の曲線名_AまたはB_UTCタイムスタンプ.png`。線の選択や表示状態で曲線名は変わりません。
- 選択した出力解像度で計算した同じ結果を表示・出力します。別品質の低解像度プレビューは使いません。拡大出力しても元写真にない細部は復元しません。
- 画像の外部送信はありません。再読み込みすると画像・編集履歴を失います。**作品データの保存・再読込は次の開発段階**です。
- 3508／5000pxはA4／A3・300ppiを考えた長辺の目安です。紙に合わせた切り抜きや、印刷サイズのメタデータ設定はありません。

## 今回の範囲と評価する点

Bは各点の採取線の左端同士、中央同士、右端同士を補間します。筋が横に移動して接続する変形ではなく、2つの色の並びのクロスフェードです。点付近の変化が穏やかになるsmoothstepを使います。

混ぜ方は「01 カラーピック」の**Bの色補間**で選びます。どの方式でも各点の採取色そのものは変わらず、点と点のあいだの通り方だけが変わります。既定は従来どおりのsRGBです。

- **sRGB（従来）**：符号化されたR/G/B成分を直接混ぜます。補色どうしの中間が暗く濁ることがあります。
- **OKLab**：知覚均等な色空間で混ぜます。中間色の明るさが保たれ、濁りが消えます。迷ったらこれです。
- **OKLCH · 色相近回り／遠回り**：明度・彩度・色相を別々に補間します。彩度を保ったまま色相が回るため、例えば赤→緑の中間が鮮やかなオレンジ（近回り）や紫側の経路（遠回り）になります。無彩色に近い側は相手の色相を借ります。
- **色相回転（OKLCH）**：近回りの経路に、区間ごとに±1〜2回転ぶんの色相の一周を追加します。2色のあいだに虹が挟まります。整数回転のみなので、点の色と区間の継ぎ目は正確なままです。

補間処理は `src/color-interpolation.ts` に分離し、方式の追加を編集UI・曲線計算から独立して行えます。

B-splineでも採取位置はクリックした制御点です。採取した色はGreville位置に対応する曲線上へ配置し、その間を補間します。重複する連続点は最後の点を代表にして、幅と採取設定を使用します。

幅が曲がりの半径より大きいと、帯が折り返して筋が重なります。端は平らに切れます。先端を細くする場合は端点の倍率を0へ近づけてください。輪郭、交差、Bの混ざり方が意図に合うかを実際の写真で評価し、次の方式・設定を相談します。

GPUのサイズ上限・メモリ不足ではエラーを表示し、勝手に解像度を下げません。A/Bとも通常のWebGL2のRGBA8テクスチャを使い、浮動小数点描画の拡張機能は不要です。長辺5000pxを検証済みですが、すべての写真・端末の速度や印刷品質を保証するものではありません。

## 開発・検証

```sh
npm test
npm run build
# 開発サーバーを起動し、Google Chromeをインストールした状態で
npm run test:browser
```

- `src/model.ts`：作品・ストローク・履歴
- `src/geometry.ts`：曲線・幅・弧長サンプリング
- `src/renderer.ts`：GLSL、GPUの色採取・A/B描画、PNG出力
- `src/ribbon-mesh.ts`：各区間と採取座標の対応
- `src/color-interpolation.ts`：色空間と補間の方針
- `src/main.ts` / `src/style.css`：編集UI
- `tests/`：数学と実ブラウザの検証

## GitHub管理とサイト公開

管理先は [ogrew/spline-smudge](https://github.com/ogrew/spline-smudge) です。
サイトURLは [Spline Smudge](https://ogrew.github.io/spline-smudge/) です。2026-09-11に所有者の承認を受けてリポジトリを公開に変更し、GitHub Pagesを有効化しました。

`.github/workflows/pages.yml` が、mainへのpush時に依存関係のインストール、テスト、公開用ビルド、Pagesへの配信を行います。配信対象は `dist` のみです。公開用ビルドは `npm run build -- --base=/spline-smudge/` を使い、ローカル開発URLは変えません。

### 公開の設定と更新

1. [Settings → Pages](https://github.com/ogrew/spline-smudge/settings/pages) のSourceは **GitHub Actions** に設定済みです。
2. 通常はmainへpushするだけで自動配信します。手動で再配信する場合は [Actions](https://github.com/ogrew/spline-smudge/actions) で **Deploy GitHub Pages → Run workflow → main** を実行します。
3. 実行成功後、公開URLで初期描画、画像選択、A/B切替、PNGエクスポートを確認します。

初回設定を済ませれば、以後mainへのpushで自動更新されます。失敗した場合はActionsの実行ログを確認します。既に公開済みのサイトは、新しいデプロイが成功するまで従来の内容を維持します。戻す場合は対象の変更を `git revert` してmainにpushします。

サイトは誰でもアクセスでき、配信されるJavaScriptも閲覧可能です。利用者が選択した画像はブラウザ内で処理され、GitHubには送信されません。編集内容は再読み込みで失われるため、必要な作品は先にエクスポートしてください。
