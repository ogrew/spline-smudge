# Spline Smudge

写真の色をスプラインに沿って引き伸ばす、TypeScript + WebGL2 + GLSLのブラウザツール。現在は写真1枚・曲線1本でA/Bを比較するプロトタイプです。

## 起動する

Node.js 22.18以上（検証環境：24.4.1）を使用します。

```sh
cd /Users/ayato/spline-smudge
npm install
npm run dev
```

[http://127.0.0.1:5173/](http://127.0.0.1:5173/) を開きます。停止はターミナルで `Control + C`。PC再起動後は同じフォルダで `npm run dev` を実行すれば再開できます。普段の起動では `npm install` は不要です。

既存のp5版（ポート8765）とは独立しています。5173が使用中の場合は、以前のSpline Smudgeサーバーが動いていないか確認してください。

## 最初に試す

1. 最初は比較用の生成パターンと、ランダムな5点の曲線が表示されます。「写真を開く」で手元のJPG／PNGを選びます。
2. 写真上をクリックして点を追加。ドラッグで移動、点をダブルクリックすると削除します。
3. 点を選択し「この点の太さ」を0〜10倍で調整します。前後へ滑らかにつながります。
4. 「採取線を移動」を選び、写真をクリックして黄色い採取線を移します。両端のドラッグか、角度・長さのスライダーで採取範囲を変えます。「点を編集」で通常の編集へ戻れます。
5. **A：色の帯**は採取した色の並びを保ちます。**B：引きずる**は通過地点の色を混ぜます。「色を拾う量」を上げるほど筋が薄まり、混色が強くなります。初期値は12%。
6. 長辺2000／3508／5000px、または元画像と同じサイズを選びます。縦横比は変わりません。
7. 「PNGを書き出す」で、点・番号・ガイドのない画像を保存します。

「ランダムな曲線」で点を置き直せます。A/Bを切り替えても点、太さ、採取範囲は共通のままです。Bの拾う量も保持します。

## 表示と編集

- 基本幅や採取長さのpxは**元写真の座標**です。出力を大きくすると作品全体が比例して拡大します。元画像の長辺2000pxで幅100pxなら、長辺5000px出力では250pxです。
- 「全体」で画面に収め、「100%」で出力の1pxを画面上の1 CSS pxに対応させます。ホイール／＋／−で拡大縮小、Space＋ドラッグまたは中ボタンで表示を移動できます。
- 番号とガイドを独立して非表示にできます。非表示でも編集できます。
- `⌘/Ctrl + Z` で取り消し、`⌘/Ctrl + Shift + Z` でやり直し。履歴は最大80件、同じ写真の編集中だけ保持します。
- 計算中も編集できます。古い計算を中断し、最新の編集で再計算します。「中断」またはEscapeで止めた場合は「再計算」を押してください。未完成画像は書き出せません。

曲線はCatmull–Rom、B-spline、Centripetal Catmull–Rom、Natural cubic、Kochanek–Bartels / TCBの5種類。TCBでは張り・つながり・偏りを調整できます。B-splineは通常内部の制御点を通らず、点の太さは対応する曲線上の位置（Greville位置）に作用します。

## 画像・出力の仕様

- JPG／JPEG、PNG入力。JPEGの向き情報を反映し、元ファイルとデコード画像をタブ内に保持します。
- **sRGB・8bit PNG出力**。透明部分は背景色に合成します。元のICCプロファイル／16bit精度をそのまま保つ制作版の色管理は未実装です。
- 出力名：`曲線名_AまたはB_UTCタイムスタンプ.png`。
- 選択した出力解像度で計算した同じ結果を表示・出力します。別品質の低解像度プレビューは使いません。拡大出力しても元写真にない細部は復元しません。
- 画像の外部送信はありません。再読み込みすると画像・編集履歴を失います。**作品データの保存・再読込は次の開発段階**です。
- 3508／5000pxはA4／A3・300ppiを考えた長辺の目安です。紙に合わせた切り抜きや、印刷サイズのメタデータ設定はありません。

## 今回の範囲と評価する点

Bは回転する色の断面を保持し、距離に応じて混色する方式です。Photoshopの指先ツールと同一ではありません。

幅が曲がりの半径より大きいと、帯が折り返して筋が重なります。端は平らに切れます。先端を細くする場合は端点の倍率を0へ近づけてください。輪郭、交差、Bの混ざり方が意図に合うかを実際の写真で評価し、次の方式・設定を相談します。

GPUのサイズ上限・メモリ不足ではエラーを表示し、勝手に解像度を下げません。Bには `EXT_color_buffer_float` が必要です。未対応端末はAで利用できます。長辺5000pxを検証済みですが、すべての写真・端末の速度や印刷品質を保証するものではありません。

## 開発・検証

```sh
npm test
npm run build
# 開発サーバーを起動し、Google Chromeをインストールした状態で
npm run test:browser
```

- `src/model.ts`：作品・ストローク・履歴
- `src/geometry.ts`：曲線・幅・弧長サンプリング
- `src/renderer.ts`：GLSL、GPUの色採取・A/B描画、PNG出力
- `src/main.ts` / `src/style.css`：編集UI
- `tests/`：数学と実ブラウザの検証
