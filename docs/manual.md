# 操作ガイド

全機能のリファレンス。UIのセクション番号（01〜05）に沿って説明します。

## 画像の読み込み

- 入力はJPG／JPEG、PNG。JPEGの向き情報（EXIF）を反映して表示します。
- 起動直後は比較用の生成パターンと、ランダムな4〜12点の曲線が表示されます。
- **画像を差し替えても、作成済みのスプラインと設定はすべて引き継がれます**。同じ曲線構成を複数の写真で試せます。
  - 全ストロークを、旧画像が新画像に収まる同一倍率で拡大縮小して中央に配置します。曲線の形と線同士の位置関係は変わりません。基本の太さと採取線の長さも同じ倍率で変わり、点ごとの倍率・採取角度・スプライン種類・TCB・A/B・色補間・オプション・背景色はそのまま保持されます。色は新しい写真から採取し直されます。
  - 差し替え自体は取り消せません。差し替えに成功すると履歴はリセットされ、新しい写真での編集から取り消しが始まります。
  - 出力解像度は、固定の長辺（2000／3508／5000px）を選んでいればそのまま、「元画像と同じ」を選んでいれば新しい画像のサイズに追従します。
  - 選択のキャンセルや読み込み失敗では、元の画像・スプライン・履歴を保持します。
- 読み込んだ画像はブラウザ内で処理され、外部へ送信されません。ページを再読み込みすると画像と編集履歴は失われます。必要な作品は先にエクスポートしてください。

## 画面と表示

- 「全体」で画面に収め、「100%」で出力の1pxを画面上の1 CSS pxに対応させます。
- ホイールはカーソル位置を中心に拡大縮小し、＋／−は画面中央を中心に動きます。Space＋ドラッグまたは中ボタンドラッグで表示を移動します。
- 「ガイド」1つで点・番号・補助線・採取線をまとめて表示／非表示にできます。非表示でも編集はできます。
- `⌘/Ctrl + Z` で取り消し、`⌘/Ctrl + Shift + Z` でやり直し。履歴は最大80件、同じ写真の編集中だけ保持します。
- 計算中も編集できます。編集すると古い計算を中断して最新の状態で再計算します。「中断」またはEscapeで止めた場合は「再計算」を押してください。計算が完了するまでエクスポートはできません。
- 点のドラッグ・スライダー操作・角度スクロールの最中は、画面サイズ相当の解像度で一時的に表示します（ステータスに「プレビュー」と表示）。操作を終えるか約0.25秒止まると、選択中の出力解像度で自動的に描き直します。出力解像度が小さく差がないときはプレビューを使いません。

## 座標系

点の位置・基本の太さ・採取線の長さのpxは、すべて**元写真の座標**です。出力解像度を変えると作品全体が比例して拡大縮小します。元画像の長辺2000pxで幅20pxなら、長辺5000px出力では50pxになります。

## 01 カラーピック — A/B/Cモードと色補間

モードは作品全体で共通です。切り替えても点配置と各モードの採取設定は保持されます。画面のボタンは「のばす・つなぐ・たどる」の名前だけを表示しますが、エクスポートのファイル名では順にA/B/Cと略記され、本ガイドでもこの略号を併用します。

- **のばす（stretch）／A** — 始点の採取線で採取した色の並びを、帯全体に沿ってのばします。
- **つなぐ（blend）／B** — 各点に採取線があり、その点で元写真から採取した色の並びを、隣り合う点のあいだでつないで補間します。筋が横へ移動して接続する変形ではなく、対応する帯幅位置どうしのクロスフェードです。
- **たどる（trace）／C** — 写真上に置いた直線の採取経路を、帯の進行に合わせてたどりながら色を採取します。経路の途中にある模様や文字がそのまま帯に現れる点がBとの違いです。進行のしかたはプリセット（等速・停止・早送り・逆走）で変えられ、停止区間では同じ断面が帯に長く続き、逆走区間では通った模様が鏡像で引き返します。

**色補間**（Bを選択中のみ表示）で点間の色の通り方を選べます。どの方式でも各点の採取色そのものは変わりません。

- **sRGB（既定）**：符号化されたR/G/B成分を直接混ぜます。補色どうしの中間が暗く濁ることがあります。
- **OKLab**：知覚均等な色空間で混ぜます。中間色の明るさが保たれ、濁りが消えます。迷ったらこれです。
- **OKLCH · 色相近回り／遠回り**：明度・彩度・色相を別々に補間します。彩度を保ったまま色相が回るため、例えば赤→緑の中間が鮮やかなオレンジ（近回り）や紫側の経路（遠回り）になります。無彩色に近い側は相手の色相を借ります。
- **色相回転（OKLCH）**：近回りの経路に、区間ごとに−2〜+2回転ぶんの色相の一周を追加します。2色のあいだに虹が挟まります。整数回転のみなので、点の色と区間の継ぎ目は正確なままです。この方式のときだけ「色相の回転数」スライダーが表示されます。

## 02 スプライン — 点と線の編集

### 点の操作

- 写真上をクリックすると点を追加します。ドラッグで移動、点のダブルクリックで削除します。空白部分のダブルクリックは点を追加しません。
- 点を選択して「この点の太さ」を0〜10倍で調整します。前後の点へ滑らかにつながります。「リセット」でその点だけ1倍に戻せます。

### 曲線の種類

Catmull–Rom、B-spline、Centripetal Catmull–Rom、Natural cubic（既定）、Kochanek–Bartels / TCBの5種類。TCBでは張り・つながり・偏りを調整できます。種類は**作品全体で共通**で、変更すると非表示の線も含む全線に適用されます。

B-splineは通常内部の制御点を通りません。点の太さとBの採取色は、対応する曲線上の位置（Greville位置）に作用します。

### 基本の太さ

整数pxで、上限は元画像の長辺÷10（小数切り捨て、最低1px）。初期値は短辺の5%（最低10px）です。各点の0〜10倍はこの基本幅に掛かります。

### ランダムな曲線

選択中の線だけを4〜12点で置き換えます。B用の採取線も点ごとにランダム化し、角度は−180〜180°、長さは短辺の5〜50%から選びます。Aの採取設定は保持します。各点の太さは前後の制御点との角度で決まり、90°未満は2〜10倍、90〜180°は0〜0.5倍から0.05刻みで選びます。角度を定義できない点（両端・隣接点が重なる点）は1倍です。生成後は手動で調整でき、点を動かしても倍率は再計算されません。

### 複数ストローク

- 一覧から編集する線を選びます。ガイド（点・番号・採取線）は選択中の線だけに表示されます。
- 一覧の上が手前です。「↑」で手前、「↓」で奥へ移動します。順序を変えても線の名前は変わりません。
- 「＋ 追加」は空の線を最前面に追加します。太さ・採取設定は選択中の線を初期値として引き継ぎ、以後独立します。
- 「複製」は同じ位置・形・設定のコピーを最前面に追加します。コピーの編集は元の線に影響しません。
- 各行のチェックで表示／非表示を切り替えます。非表示の線はガイドとエクスポートから除外され、キャンバス上の点操作も受け付けませんが、設定は保持されます。
- 「削除」は選択した線を削除します。最後の1本を削除すると空の線が1本残ります。「点をクリア」は選択した線の点だけを消します。
- 追加・複製・削除・表示切り替え・順序変更・ランダム生成はすべて取り消しに対応します。
- 各線の採取元は他の線の描画結果ではなく、常に元写真です。

## 03 採取線

- Aでは始点の採取線（1本）を、Bでは選択中の点の採取線を、Cでは経路上を動く採取線（角度・長さ固定）を編集します。角度と長さをスライダーで調整します。
- 採取線の中心は、A/Bでは点の位置に追従します。Cの採取経路は点から独立していて、写真上の**黄色い端点をドラッグ**して動かします。経路上の小さな印は進行キーの位置（写真側＝どこを通るか）、曲線上の印は対応する帯の位置（＝いつ通るか）です。
- Cの進行はプリセットの3種（等速／停止・早送り／逆走）から選びます。進行キーの自由編集は評価後の検討事項です。
- 新しい点の角度・長さの初期値は、その時点のA設定からコピーされます。
- 点を選択中、画像上でShift＋上スクロールで採取角度が増え、下スクロールで減ります。±180°を越えると循環します。連続する角度スクロールは1回の取り消しにまとまります。Shiftを押しているあいだはズームしません。

## 04 オプション

どちらも既定OFFで、OFFのときの出力は無効時と完全に一致します。チェックを入れると設定が現れます。作品全体に効き、取り消し・エクスポートに対応します。

- **写真で帯を変形** — 2つのアルゴリズムから1つを選びます。調整値はアルゴリズムごとに保持されます。
  - *輝度ディスプレイスメント*：帯の各位置を、その場所の写真の明るさに応じて帯の法線方向へ押し出します。変位量は短辺比％で、負の値で方向が反転します。
  - *エッジで幅を変調*：写真の輪郭の強さに応じて帯の幅を伸縮します。効きが正でエッジ部分が太く、負で細くなります。
- **フェイク3D** — 帯の断面に円筒状の陰影とハイライトを付け、リボンの物質感を出します。強さは0〜1（初期値0.65）、光源は左上固定です。
- **習字のかすれ** — 帯の中に、筆の毛筋のような未着色や半透明の掠れが走ります。帯の縁ほど欠けやすく、幅0へ絞った先端は自然にかすれて消えます。「毛筋の間隔」は元画像px基準で、出力解像度を変えても毛筋の本数は変わりません。模様は固定シードで、再計算・書き出しでも同じ形が再現されます。
- **光のにじみ** — 帯の両側に、縁の色が減衰しながら広がる光のハローを付けます。長時間露光の車のライトの軌跡のような表現です。「ひろがり」はハローの幅（帯の太さの倍率、0.1〜4）で、太さや解像度の変更に自動で追従します。「変化」を正にすると終点へ向かうほど拡散が広がり、負で逆になります（±1で反対端のハローは閉じます）。「芯の輝き」は帯の中心に沿って白く飛んだ細いフィラメントを乗せる露光オーバーの表現です。帯が重なる箇所は手前が奥を覆う通常の合成で、実写のような加算発光にはなりません。

## 05 エクスポート

- 長辺2000／3508／5000px、または元画像と同じサイズ（既定）を選びます。縦横比は変わりません。3508／5000pxはA4／A3・300ppiを想定した長辺の目安です。
- 出力は**sRGB・8bit PNG**。透明部分は選択した背景色に合成します。ICCプロファイルや16bit精度の保持は未対応です。
- ファイル名は `スプライン種類_モードの略号（A/B/C）_UTCタイムスタンプ.png`。
- 確定表示とエクスポートは、選択した出力解像度で計算した結果そのものです。操作中の一時プレビュー（「画面と表示」参照）は操作後に必ず出力解像度へ置き換わり、プレビュー表示中はエクスポートできません。拡大出力しても元写真にない細部は復元されません。
- ガイド（点・番号・採取線）は出力に含まれません。

## 表現上の性質と制約

- 幅が曲がりの半径より大きいと、帯が折り返して筋が重なります。自己交差は描画順に上書きされます。
- 帯の端は平らに切れます。先端を細くしたい場合は端点の倍率を0へ近づけてください。
- 写真の外を採取した部分は、端の色を延長します。
- GPUのサイズ上限やメモリ不足のときはエラーを表示します。解像度を勝手に下げることはありません。
